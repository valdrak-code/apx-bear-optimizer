# Cloudflare Pages Deploy

1. Upload/replace all files from this package into the GitHub repository root.
2. Commit with: `APX Tools v2.1 RC1 complete site`
3. Cloudflare Pages should auto-deploy from GitHub.
4. Test these URLs after deployment:
   - /
   - /guide.html
   - /about.html
   - /changelog.html
   - /favicon.ico

If the favicon does not update, test in another browser or purge Cloudflare cache.
