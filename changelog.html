📋 Release Notes

Current Release Candidate

This changelog tracks meaningful APX Tools updates. Development builds are summarized by release theme so testers can see what actually changed.

v2.4.9 RC3 — Input Performance Patch

Status: Release Candidate

  • Stopped the optimizer from recalculating on every keystroke while troop values are being entered.
  • Results now update when LET'S GOOOO! is pressed, eliminating heavy typing lag on slower phones and computers.
  • Removed duplicate calculations previously triggered by input, change, and blur events.
  • Kept comma formatting on field exit without rerunning the Adaptive Formation Engine.
  • No formation-logic changes; Adaptive Formation Engine remains v2.4.7.

v2.4.7 RC1 — Adaptive Formation Engine Release Candidate

Status: Release Candidate

  • Promoted the v2.4 development work into a release-candidate package for broader testing.
  • Updated visible Recommendation Quality so it grades the Joiner Formation directly instead of being pulled down by the Rally Leader reference.
  • Elite full-cap, high-Archer joiner formations can now display S Rank appropriately.
  • Preserved Rally Leader quality inside the hidden optimizer score without letting it confuse the visible joiner rank.
  • Kept the expanded Copy Output so test reports include inputs, APX Recommended Setup, Rally Leader Formation, Maximum Marches Setup, Maximum Marches Rally Leader Formation, version, engine, and priority state.

v2.4 Development Series — Adaptive Formation Engine

Status: Development foundation for RC1

  • Introduced the Adaptive Formation Engine approach for candidate evaluation.
  • Refactored optimizer behavior so Rally Leader Priority changes candidate weighting instead of relying on fully separate construction paths.
  • Added exact troop allocation inside optimizer math, removing intentional rounding from the engine.
  • Improved Candidate/Recommendation packaging so APX Recommended and Maximum Marches outputs stay consistent when they represent the same march count.
  • Fixed cases where Maximum Marches could show a conflicting or stronger Rally Leader Formation than the APX Recommended package when both used the same number of marches.
  • Improved Rally Leader Priority weighting so enabling the toggle meaningfully favors stronger Rally Leader Formations.
  • Improved flexible Rally Leader target handling so the entered Rally Leader Target Size is treated as an ideal target rather than an absolute forced size.
  • Added fuller practical Rally Leader Formation candidates so the engine is not trapped by exact 10 / 10 / 80 when Cavalry backfill creates a better usable formation.
  • Expanded Leader and Joiner candidate comparison around total formation usefulness rather than ratio-only stopping points.
  • Improved low- and mid-troop behavior where forcing one side too hard could previously create weak or misleading outputs.

v2.3 Beta Series — Role Simplification & Formation Integrity

Status: Beta / engine stabilization

  • Removed the Balanced strategy after testing showed players are effectively optimizing as either joiners or Rally Leaders.
  • Removed the strategy dropdown and replaced it with one clearer toggle: Prioritize Rally Leader Formation.
  • Rally Leader Target Size is now always visible and always used to show a Rally Leader Formation reference.
  • Joiner-first mode optimizes Joiner Formations while still showing a Rally Leader Formation reference.
  • Rally Leader priority mode prioritizes the Rally Leader Formation while keeping joiners viable.
  • Added Formation Integrity rules including minimum Infantry presence and Cavalry viability checks.
  • Added Archer scaling beyond the original 70% joiner target for high-Archer accounts.
  • Added automatic advanced Rally Leader milestone behavior for 1 Infantry / 10% Cavalry / 90% Archers when the account can support it.
  • Protected joiner viability so advanced Rally Leader progression does not activate at the expense of functional joiner marches.
  • Added exact count plus percentage display for Rally Leader Formation cards.
  • Improved advanced Archer sharing between joiners and Rally Leader Formation.
  • Improved Cavalry backfill behavior toward the Alliance Rally Cap when safe.
  • Fixed high-Archer candidate rejection caused by tiny rounding leftovers.
  • Fixed APX Coach so it no longer recommends reducing marches just to chase 100% Archer joiners.
  • Restored polished pill-style navigation across pages.
  • Cleaned up the Rally Leader priority toggle layout and helper text.
  • Added configurable APX / Kingdom 1886 language foundation for future expansion.
  • Added OPTIMIZER_RULES.md and ROADMAP.md for future development tracking.
