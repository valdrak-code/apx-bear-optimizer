📋 Release Notes

Current Beta Release

This changelog tracks meaningful APX Tools updates. Minor behind-the-scenes edits may not always be listed individually.

v2.3.5 Beta — Adaptive Optimization Beta

Status: Beta testing

  • Removed the Balanced strategy after testing showed players are effectively optimizing as either joiners or Rally Leaders.
  • Removed the strategy dropdown and replaced it with one clearer toggle: Prioritize Rally Leader Formation.
  • Rally Leader March Size is now always visible and always used to show a Rally Leader Formation reference.
  • Joiner-first mode now optimizes joiner Formations while still showing a Rally Leader Formation reference.
  • Rally Leader priority mode now prioritizes the Rally Leader Formation while keeping joiners viable.
  • Restored polished pill-style navigation across pages.
  • Fixed Rally Leader priority toggle layout and removed the awkward gold hover box around the checkbox area.
  • Updated Guide, About, Changelog, README, Roadmap, and Optimizer Rules for the v2.3 beta direction.

v2.3.0–v2.3.4 Dev Series

Status: Development testing

  • Added Formation Integrity rules including a minimum Infantry presence and Cavalry floor targets.
  • Added Archer scaling beyond 70% for high-Archer joiner Formations.
  • Added automatic advanced Rally Leader milestone detection: 1 Infantry, roughly 10% Cavalry, and roughly 90% Archers.
  • Protected joiner Formations so advanced Rally Leader progression only activates when joiners remain 70%+ Archers.
  • Added exact count plus percentage display for Rally Leader Formation cards.
  • Improved advanced Archer sharing between joiners and Rally Leader Formation.
  • Fixed high-Archer candidate rejection caused by tiny rounding leftovers.
  • Improved advanced-mode Cavalry backfill so joiners continue pushing toward the Alliance Rally Cap Limit when viable.
  • Fixed APX Coach so it no longer recommends reducing marches just to chase 100% Archer joiners.
  • Added configurable APX / Kingdom 1886 language foundation for future expansion.
  • Added OPTIMIZER_RULES.md and ROADMAP.md for future development tracking.

v2.2.0 — Official Release

Status: Official release

  • Promoted APX Tools from Release Candidate to official release.
  • Added Guide, About, and Changelog pages.
  • Added Copy Recommendation for Discord sharing.
  • Finalized APX Coach, APX Insight, Optimization Report, and Formation cards.
  • Prepared production package for Cloudflare Pages deployment.
